# Aionain Listing Creator

This repository contains the module `alc` which can parse the Aionain resources, and outputs it into different formats, including JSON and SQLite.

The said output files are available in a linked submodule, and is available for download.

## Building

This module has no dependancies, and can be run without downloading any external pip package. Run the module alc using `python -m alc`, or import it in your project.

To see the example usage, check out the `.vscode/launch.json` file, which can be used to debug the program. Don't forget to close the submodules before doing so.
